QHturbo PHP

EN · VI Refresh lists
PHP 7.4–8.5 built from the official source, running beside DirectAdmin's PHP (which is never changed). Each domain is switched on its own; its user gets a PHP-FPM pool in QHturbo that runs as that user, with the same limits as DirectAdmin's pool. A domain that answers with an error after the switch is switched back automatically.
