Start safely: snapshot the server, then switch a test site first.

          
    
            
  1. PHP versions → Install the version your site uses (for example 7.4 for a site on aaPanel PHP 7.4). Extensions of aaPanel's PHP of that version are copied automatically.
    2. 
            
  2. Sites → choose the version → Switch. Open the site and check it.
    3. 
            
  3. Back to aaPanel PHP undoes it at any time.
    4. 
          

          
Command line (same actions): /opt/qhturbo-src/scripts/aapanel.sh check|install|enable|disable|status

          
Guide: docs/aapanel.md · Website: qhsvn.github.io/QHTurbo · Issues: GitHub

        

        

          
Bắt đầu an toàn: snapshot máy chủ, rồi chuyển thử một site phụ trước.

          
    
            
  1. Phiên bản PHP → Cài đặt đúng phiên bản site đang dùng (ví dụ 7.4 cho site chạy PHP 7.4 của aaPanel). Extension của PHP aaPanel cùng phiên bản được chép sang tự động.
    2. 
            
  2. Site → chọn phiên bản → Chuyển. Mở site để kiểm tra.
    3. 
            
  3. Về PHP aaPanel để quay lại bất cứ lúc nào.
    4. 
          

          
Dòng lệnh (cùng thao tác): /opt/qhturbo-src/scripts/aapanel.sh check|install|enable|disable|status
